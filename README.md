## **Butterfly**

This is a program written in Python that uses Javascript libraries such as mineflyer.
This bot is written inside 1 file due to technical reasons․
The goal of this program is to create a simple environment
for using the library through an intuitive interface written using the Tkinter library.

The bot supports 2 global modes




***Battles**
This is a mode for battle purposes. It has 3 sub-modes.*

**Follow**
The bot follows the player, it will find you even if you are at the barrier, it has artificial intelligence built into it that finds the optimal path to the goal

**Hunting**
Almost the same, but the bot now analyzes objects and adapts for battle, studying your strategy.

**Protection**
He will protect you from all the entities that attacked you, “Even the players.”




***Production**
This is a mode for all sorts of industrial activities,
You will have to set the place of the chest for storing items, It has 3 modes*

**Fishing**
He will fish in the place you indicated

**Mining**
He will look for the ore you choose

**Farming**
He will take care of the crops within the radius you specify
